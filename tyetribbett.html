Tye Tribbett

Refactoring an artist storefront's footer with Shopify's native components to fix alignment and make it easier to maintain.

D2C Engineering Intern

TOOLS

Shopify, Liquid, HTML, CSS

BACKGROUND

Tye Tribbett is a Grammy-winning gospel artist. During my internship at Universal Music Group (Fame House), I worked on his Shopify merchandise storefront.

CHALLENGE

The storefront's footer looked misaligned: the social media icons, navigation links, and legal information didn't line up cleanly with each other.

The original footer was heavily customized. It used a custom developer container and Font Awesome icons for social links, and positioned elements with absolute positioning and negative margins that were adjusted through several media queries. These manual overrides were fragile across screen sizes and difficult to maintain.

SOLUTION

I refactored the footer to use Shopify's built-in footer components and the theme's responsive layout utilities instead of custom positioning overrides.

Social links, navigation, and legal information are now organized into separate sections within the theme's grid, resolving the alignment and spacing issues while keeping the storefront's branding and functionality.

MY CONTRIBUTION

Replaced the custom social icon container with Shopify's social-container component, and swapped Font Awesome icons for inline SVG icons.

Removed the absolute positioning and negative-margin overrides, and rebuilt the layout with the theme's grid and Flexbox utility classes, such as md:col-span-4 and md:flex.

Applied the theme's typography and color classes in place of custom font sizes and colors, so the footer stays visually consistent with the rest of the storefront.

  min-width: 100%;
  position: absolute;
  margin-left: -40%;

.menu-nav {
  margin-right: -35%;
  margin-left: -10%;
}

After

Each section sits in the theme's responsive grid instead: 

<div class="footer__griditem footer__griditem--0
            footer__griditem--social
            md:col-span-4 md:row-span-1">

Implementation Details

I refactored the footer using Shopify's native components and responsive layout utilities, resolving alignment and spacing issues while improving visual consistency and maintainability. Rather than adding more overrides, I simplified a heavily customized implementation by building on the theme's existing structure.
