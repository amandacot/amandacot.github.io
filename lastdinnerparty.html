The Last Dinner Party

Customizing Shopify storefront components to reflect the band's distinctive visual identity and create an interactive shopping experience.

Scroll to explore ↓

D2C Engineering Intern

COMPANY

TIMELINE

Summer 2024

TOOLS

BACKGROUND

The Last Dinner Party is a British indie rock band known for its theatrical aesthetic and distinctive visual identity. During my internship at Universal Music Group (Fame House), I worked on customizing the band's Shopify merchandise storefront.

CHALLENGE

Customize the storefront's default Shopify buttons to better reflect the band's visual identity and create a more cohesive shopping experience.

Incorporate decorative, artist-branded button designs while maintaining consistent styling and functionality across different storefront components.

Implement interactive hover effects that complement the band's aesthetic and provide visual feedback to users.

SOLUTION

Replace standard Shopify button styling with custom, artist-branded imagery to create a more distinctive and visually cohesive storefront.

Introduce interactive hover states that swap background images and text colors, creating a seamless transition between the buttons' default and hover appearances.

MY CONTRIBUTION

Developed custom CSS styling for multiple Shopify button components, including primary, secondary, and email signup buttons.

Implemented custom background images, adjusted sizing, padding, and text colors, and used CSS :hover selectors to create interactive button states.

Integrated the band's decorative button designs into the existing Shopify theme while maintaining consistent dimensions and styling across the storefront.

Custom Button Implementation

Custom button styling using artist-branded imagery, with separate default and hover states to create an interactive experience.

Default State

Hover State

Implementation Details

Using CSS, I applied custom background imagery to Shopify's button components and adjusted their dimensions, spacing, and typography. The :hover state replaces the default button image with a separate hover asset and changes the text color, providing interactive visual feedback while maintaining the band's distinctive aesthetic.
